# Smooth Vector Scrollbar

Smooth interactive vector scrollbar with diagnostics overview markers

## Details
- **Identifier**: `matn.ext.scroller`
- **Version**: `1.0.0`
- **Category**: `editor`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Smooth Vector Scrollbar**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-scroller
```
